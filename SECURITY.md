# Security Policy

## Supported Versions

The project is pre-`v1.0.0`; security fixes are applied on the default branch.

## Reporting a Vulnerability

Do **not** open public issues for vulnerabilities.

Use GitHub private vulnerability reporting:
- [Report a vulnerability](https://github.com/SamyRai/bank-data/security/advisories/new)

When reporting, include:
- affected package(s)
- reproduction input/data
- impact assessment
- proposed mitigation (if available)

We target:
- acknowledgement within 48 hours
- critical mitigation path within 7 days
